# 🏥 مستشفى النور التخصصي | Al-Noor Specialized Hospital

A modern, bilingual (Arabic/English), multi-page hospital website with gradient colors, animations, and dynamic language switching.

## 👨‍💻 Developer
**Ali Fathi**

## ✨ Features

- 🌍 **Full Bilingual Support** (Arabic RTL / English LTR) with one-click switch
- 🎨 **Modern Gradient Design** with animated floating orbs
- 🎬 **Smooth Animations** (scroll reveal, counters, floating cards, gradient shift)
- 📱 **Fully Responsive** design for all devices
- ⚡ **Dynamic Counters** that animate on scroll
- 📄 **5 Pages**: Home, About, Services, Doctors, Contact
- 📅 **Appointment Booking Form** with success feedback
- 🔍 **SEO friendly** semantic HTML
- ♿ **Accessibility** with ARIA labels & reduced motion support
- 💾 **Language Preference Saved** in localStorage
